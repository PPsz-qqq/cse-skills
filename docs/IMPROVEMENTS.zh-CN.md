## 主要修正

| 问题 | 本轮处理 |
|---|---|
| 简单润色/缺材料诊断也被全流程门禁阻塞 | 新增共享执行约定与四种模式；局部编辑、诊断、计划可以先做，最终主张仍需适用证据检查 |
| G2 与审稿形成循环依赖 | 明确诊断审稿不要求先 G2 PASS；缺证据是审查对象，不能假通过 |
| 新版冻结产物无法按旧固定文件名交接 | 增加当前产物索引与修订后缀规则，保留旧冻结版本及稳定 claim ID |
| 判定与过期状态混在一起 | 六种 verdict 与 current/STALE 分离；历史 PASS 保留但过期后不得用于提升主张 |
| measured、simulation 和 re-implemented 混为同一分级 | 拆分证据 tier、场景、基线来源与核验状态；用户给值不自动等于独立核验 |
| ANEES 默认把全部连续时间步当独立样本 | 默认逐时刻跨独立 Monte Carlo runs，df=N*n_x、卡方分位数除以N；时间池化必须证明独立性或校准相关性 |
| 对角协方差日志被当成足够计算 NEES | 要求完整协方差或充分分解，除非协方差确实是对角矩阵 |
| 区间包含零被写成等价/无效果 | 改为不确定；等价需要预声明 margin 和对应检验，不能反复加seed直到显著 |
| AP 不确定度的统计单位不清 | 重采样独立场景/序列并重算官方指标，不能简单平均每图AP或任意改成跨类别估计 |
| pilot预算量纲、effort tier和强制timeout不一致 | 分清墙钟小时与GPU数×占用时间；预留最坏用量，升级需显式决策，命令转后台不是硬终止 |
| pilot后选择阈值又追认为预注册结果 | pilot保持探索性，记录影响，后续独立确认性阶段再冻结 |
| 审稿隔离被说成统计独立；零未解问题被判成不独立 | 隔离只降低泄漏，模拟报告不保证统计独立；取消未解意见配额，允许全部问题有据关闭 |
| 既有证据无论充分程度都不能纠正审稿人 | 改按相关性与充分性评分，先前遗漏的材料可以关闭误判 |
| 引用审计无真值却要求FPR/FNR | 没有独立裁定真值就只报覆盖和分类，FPR/FNR写not estimable |
| sketch仍强制跑第三轮检索 | 按effort tier限制扩展，未跑轮次不写产出或饱和结论 |
| 两个近期周期被当成历史首次证明 | 加入基础工作、搜索边界和near misses；优先写有范围的检索发现 |
| interaction表缺基准配置、回复run决策有无效分支 | interaction明确四配置；正负结果都报告是义务而非自动开跑判据；返修停止条件统一到共享规范 |
| 3分钟报告被套进14页结构 | 补3/5分钟结构，时长只统计正文、不含问答与备用页，预留至少10% |
| 简化YAML解析/只计8个文件导致漏检 | 共享真实YAML兼容模块，检查八个不同的预期名称；支持flat/junction、非法字段类型、重复键、BOM及带空格链接 |
| 离线解析被描述为当前运行时已启用 | 明确离线检查与实际provider启用/根目录/会话可见性是不同验证 |
